# 영업 대상 업종 순환표 (초안 — 사용자 확인 필요)

최근 5영업일에 쓴 업종은 피한다. 새 영업 대상이 생기면 여기에 추가한다.

| 업종 | 독자(광고주)가 겪는 문제의 방향 | 비고 |
|---|---|---|
| 청소용품 | 쇼핑검색광고 상품정보·효율 점검 | 기존 글 있음 |
| 박람회 주최사 | 참관객 모집용 DB 수집 광고 | 기존 글 있음 |
| 숙박(한옥스테이·펜션) | 플랫폼 의존, 비수기 공실 | 기존 글 있음 |
| 병원 | 의료광고 규정 안에서의 퍼포먼스 | 확인 필요 |
| 이커머스 | 쇼핑·메타 광고 효율 | 확인 필요 |

주제 기준: 영업 대상 업종의 광고주가 겪는 문제 + 최근 30일 안의 공식 발표·정책 변경.
